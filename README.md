## Лабораторная 3.1 — сортировка подсчётом

Сортировка целых чисел от 0 до 127 по возрастанию. Сначала подсчитываются
частоты значений, затем результат записывается в исходный список.

- `3.1/Sorting.java` — интерфейс сортировки.
- `3.1/CountingSort.java` — реализация метода `sort(List<Integer> nums)`.

Метод принимает изменяемый список; отдельный `Main` и вывод в консоль не нужны.
Для `ArrayList` время работы — `O(n + K)`, дополнительная память — `O(K)`,
где `n` — число элементов, `K = 128`. При фиксированном диапазоне это
`O(n)` времени и `O(1)` дополнительной памяти.
